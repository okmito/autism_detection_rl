How it works
  • The policy chooses which question to ask next (max 6 of 10).
  • Greedy is deterministic: it always picks the question with the highest expected information gain — the same answers give the same sequence by design.
  • Random draws a fresh random sequence each episode — a baseline for comparison.
  • After each answer the model updates the risk estimate.
  • “Stop & predict” ends early and gives the recommendation.
  • Auto mode replays a full episode from the held-out test set.
